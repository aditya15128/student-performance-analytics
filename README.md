# Student Performance Analytics System

## Project Overview
The Student Performance Analytics System is a Python-based project that analyzes student academic performance using Pandas and NumPy.

## Objectives
- Calculate total and average marks.
- Assign grades based on average marks.
- Identify pass and fail results.
- Find top-performing students.
- Compare subject-wise and department-wise performance.
- Analyze student attendance.

## Technologies Used
- Python
- Pandas
- NumPy
- CSV

## Project Files
- `main.py` — Main program and analysis functions.
- `students.csv` — Sample student dataset.
- `student_results.csv` — Generated analysis results.

## How to Run
1. Install Python.
2. Install dependencies using `pip install pandas numpy`.
3. Place `students.csv` in the same folder as `main.py`.
4. Run `python main.py`.

## Output
The program displays student totals, averages, grades, pass/fail status, subject averages, department comparisons, grade distribution, and low-attendance alerts.

## Dataset Note
The included student records are sample data created for demonstration purposes.

## Conclusion
This project demonstrates how Python, Pandas, and NumPy can be used to organize student data and generate useful academic performance summaries.
